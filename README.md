# 🚗 Sistema Lava Jato - API

API desenvolvida em **FastAPI** para o gerenciamento completo de um sistema de lava-jato, controlando ordens de serviço, clientes, veículos, funcionários e caixa.

## 🛠️ Tecnologias Utilizadas

As principais tecnologias e ferramentas empregadas no desenvolvimento do backend:

* **[FastAPI](https://fastapi.tiangolo.com/)** - Framework web moderno e de alto desempenho para construção de APIs em Python.
* **[SQLAlchemy](https://www.sqlalchemy.org/)** - Ferramenta ORM para mapeamento objeto-relacional e manipulação do banco de dados.
* **[MySQL](https://www.mysql.com/)** - Sistema de gerenciamento de banco de dados relacional.
* **[Pydantic / Pydantic-Settings](https://docs.pydantic.dev/)** - Validação de dados robusta e gerenciamento seguro de variáveis de ambiente.
* **[Uvicorn](https://www.uvicorn.org/)** - Servidor ASGI para rodar a aplicação FastAPI.
